# Caso comentado 2 — Paracas 1935.32.0212

## Por qué está aquí
Este registro obliga a diferenciar entre descripción, técnica, iconografía y conservación.

## Qué enseña
- Cómo una nota técnico-curatorial usa materialidad y técnica.
- Cómo la recuperación apoya comparación sin colapsar objetos distintos.
- Cómo explicitar incertidumbre aunque la ficha sea rica.

## Qué se puede afirmar
- fragmentos de manto;
- block style;
- base de algodón y bordado de lana;
- 16 colores;
- motivo antropomorfo con elementos serpentiformes;
- atribución Paracas Necrópolis.

## Qué no se debe afirmar
- lectura simbólica cerrada;
- función ritual exacta;
- reconstrucción total del manto.
