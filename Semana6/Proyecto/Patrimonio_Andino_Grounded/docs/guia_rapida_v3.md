# Guía rápida v3

## Para una primera revisión

1. Abrir `notebooks/07_demo_integrada_y_modelo_real_opcional.ipynb`.
2. Revisar `data_processed/records_master.jsonl`.
3. Leer `docs/casos_comentados/resumen_casos.md`.
4. Abrir `notebooks/09_casos_comentados_en_profundidad.ipynb`.

## Para una corrida local con GPU

1. Revisar `configs/4080_opcional.yaml`.
2. Revisar `configs/modelos_reales_opcionales.yaml`.
3. Abrir `notebooks/08_corrida_local_rtx4080_opcional.ipynb`.

## Resultado mínimo esperado

- recuperación textual y estructural sobre la muestra real pequeña;
- generación grounded con evidencia visible;
- una corrida opcional con BLIP para captioning real si hay activos descargados;
- dos casos comentados con lectura cercana y límites explícitos.
