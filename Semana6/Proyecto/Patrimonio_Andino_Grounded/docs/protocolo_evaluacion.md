# Protocolo de evaluación

## Modos de comparación
1. solo texto catalográfico
2. texto + estructura
3. texto + estructura + recuperación
4. texto + estructura + recuperación + plausibilidad

## Métricas operativas
- cobertura de atributos
- apoyo de recuperación
- acuerdo con metadatos
- tasa de alucinación por reglas simples
- plausibilidad estructural

## Lectura correcta
Estas métricas son **operativas internas**.
No sustituyen métricas estándar de benchmark ni juicio curatorial experto.

## Evaluación cualitativa
La revisión manual debe mirar:
- precisión factual
- utilidad descriptiva
- disciplina inferencial
- claridad sobre incertidumbre
