# Guía rápida v2

## Apertura recomendada
1. `notebooks/07_demo_integrada_y_modelo_real_opcional.ipynb`
2. `notebooks/03_recuperacion_base_e_indices.ipynb`
3. `notebooks/04_generacion_grounded.ipynb`
4. `notebooks/06_casos_curatoriales_y_exportacion.ipynb`

## Idea de uso
- usar `07` para una primera lectura compacta del proyecto;
- usar `00–06` cuando se quiera reconstruir el pipeline completo;
- dejar la ruta con BLIP como extensión opcional cuando haya GPU o una imagen local de prueba.

## Nota
Esta versión no incluye una rúbrica de evaluación.
