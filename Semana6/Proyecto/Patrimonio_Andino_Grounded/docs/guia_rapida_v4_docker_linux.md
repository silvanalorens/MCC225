## Orden mínimo de uso

1. Levantar el contenedor del curso.
2. Abrir JupyterLab.
3. Ejecutar `notebooks/10_verificacion_entorno_docker_linux.ipynb`.
4. Ejecutar `notebooks/07_demo_integrada_y_modelo_real_opcional.ipynb`.
5. Si hay GPU disponible, probar `notebooks/08_corrida_local_rtx4080_opcional.ipynb`.
