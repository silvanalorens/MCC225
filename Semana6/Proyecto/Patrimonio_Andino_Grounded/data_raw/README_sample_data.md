# Nota sobre los datos incluidos

Esta carpeta incluye **metadatos reales pequeños y curados**.
No redistribuye imágenes patrimoniales externas.

Si deseas trabajar con imágenes locales:
1. agrega las rutas o URLs en un manifest,
2. usa `src/fetch_remote_assets.py`,
3. actualiza `image_path` en los registros normalizados.
